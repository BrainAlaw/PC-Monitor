# Worker assignment authoring guide

The coordinator supplies an actual complete task in the mission's `prompt` field. Include the outcome, interfaces to preserve, source files to inspect, meaningful milestones, regression and edge cases, and any real-machine limitations.

Do not paste this authoring guide as the worker's task. The runner adds the worktree, branch, owned paths, TDD policy, prior repair feedback and JSON report contract, then publishes the resulting assignment before launching the worker.
